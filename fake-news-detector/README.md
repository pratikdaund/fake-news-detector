# Veritas — Fake News Detection System

> M.Tech academic project · NLP + Deep Learning · Streamlit + Render

A web application that classifies news articles as **REAL** or **FAKE** using two models:
- **TF-IDF + Logistic Regression** — a strong classical NLP baseline
- **Bidirectional LSTM** — a deep learning model with learned word embeddings

Trained on the ISOT Fake News Dataset (~44,000 articles).

## 🚀 Quick Start (5 steps)

### 1. Clone and set up environment

```bash
git clone <your-repo-url> fake-news-detector
cd fake-news-detector

python -m venv venv

# Activate:
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Download the dataset

Get the ISOT Fake News Dataset from Kaggle:
https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

Place `Fake.csv` and `True.csv` inside the `data/` folder.

### 3. Train the models

```bash
# Train both models (recommended, takes 5–15 min)
python train.py

# OR train only logistic regression (1–2 min, smaller file)
python train.py --skip-lstm

# OR quick test with a 5,000-sample subset
python train.py --sample 5000
```

You should see output like:

```
===== Logistic Regression =====
Accuracy: 0.9934
              precision    recall  f1-score   support
        FAKE       0.99      0.99      0.99      4697
        REAL       0.99      0.99      0.99      4283
```

### 4. Run the app locally

```bash
streamlit run app.py
```

Open http://localhost:8501 in your browser.

### 5. Deploy to Render (see below)

## 🌐 Deploying to Render (Free Tier)

Render's free tier gives you a public URL, HTTPS, and auto-deploy from Git. Service sleeps after 15 min of inactivity (~30s cold start).

### Step-by-step

1. **Commit your trained models to Git.** Render needs them at build time.
   - `logreg_model.pkl` (~2 MB) — always safe to commit
   - `lstm_model.keras` (~15–50 MB depending on vocabulary) — commit if under 50 MB, else use Git LFS
   - If your repo exceeds 100 MB, either use Git LFS or skip the LSTM entirely

   ```bash
   git add models/logreg_model.pkl models/tfidf_vectorizer.pkl
   git add models/lstm_model.keras models/lstm_tokenizer.pkl    # optional
   git commit -m "Add trained models"
   git push
   ```

2. **Sign up at [render.com](https://render.com)** (free, use your GitHub account).

3. **New → Blueprint** — point Render at your GitHub repo. It will auto-detect `render.yaml` and configure everything.

   *Manual alternative:* New → Web Service, then fill in:
   - **Runtime:** Python 3
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:**
     ```
     streamlit run app.py --server.port $PORT --server.address 0.0.0.0 --server.headless true --server.enableCORS false
     ```
   - **Plan:** Free

4. **Click Deploy.** First build takes 5–10 minutes.

5. Visit the `*.onrender.com` URL Render gives you.

### If the free tier runs out of memory

TensorFlow + LSTM on 512 MB RAM is tight. If you see "Out of memory" in Render logs:

1. Rename `requirements-light.txt` → `requirements.txt` (removes TensorFlow).
2. Remove `models/lstm_*` files from Git.
3. The app auto-detects missing models and falls back to logistic regression only.
4. Push and redeploy.

## 🔬 Expected Accuracy

On the ISOT dataset's held-out test set (20% split):

| Model | Accuracy | Notes |
|---|---|---|
| Logistic Regression | ~99.3% | Very high because the dataset has strong lexical cues |
| Bidirectional LSTM | ~99.5% | Marginal improvement, higher compute cost |

**⚠️ Don't celebrate these numbers.** The ISOT dataset has known biases — all real news comes from a single source (Reuters) and all fake news from ~200 fake news sites. Your model is learning *"what does a Reuters article look like"*, not *"what is truth"*.

Real-world fake news detection on unseen sources typically drops to 60–75% accuracy. Mention this in your thesis limitations section — examiners will respect the honesty.

## 🛠 Troubleshooting

**`FileNotFoundError: Fake.csv`** — Dataset not in `data/`. Download from the Kaggle link above.

**`No trained models found`** — Run `python train.py` before `streamlit run app.py`.

**NLTK download errors** — Run once manually:
```python
python -c "import nltk; nltk.download('stopwords'); nltk.download('wordnet'); nltk.download('omw-1.4')"
```

**Render build fails with "No space left on device"** — Use `requirements-light.txt` and skip LSTM.

**Streamlit shows blank page** — Check browser console. Usually fixed by `pip install --upgrade streamlit`.

**TensorFlow install hangs on Windows** — Use `tensorflow-cpu` not `tensorflow` (already in requirements).
